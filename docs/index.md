# AURA One Indoor

**AURA** es un proyecto de monitorización ambiental interior, basado en un microcontrolador ESP32-S3. Busca funcionamiento local, privacidad, fiabilidad y arquitectura modular.

## Componentes

- **ESP32-S3 N16R8:** plataforma base.
- **ILI9341:** pantalla TFT SPI.
- **SCD41:** sensor de CO₂; integración eléctrica no autorizada todavía.
- **BME280:** sensor ambiental, pendiente de integración.

El firmware histórico está identificado como paquete AURA Display v0.9, con discrepancia respecto a la versión interna indicada en su configuración.

Esta web está en preparación. La presencia de documentación no acredita pruebas funcionales.
